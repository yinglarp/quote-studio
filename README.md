# Quote Studio

Tools and reference material for producing Heicoders Catering quotations.

## Folders

- `design/` – brand tokens, fonts, logo and the quotation design checklist
- `inputs/` – customer enquiries to quote from
- `reference/` – price list, terms and conditions, memos and meeting notes
- `outputs/` – generated quotes (not tracked by Git)

## Kept out of Git

The `.gitignore` excludes confidential files (`staff/`, `reference/costing-and-margins.xlsx`),
secrets (`.env` files) and generated files (`outputs/`). Never force-add them.
